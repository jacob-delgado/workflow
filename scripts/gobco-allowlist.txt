# The condition arms no test reaches that a kept trade-off keeps. The gate is
# scripts/gobco-report.sh (task cover:branch), which fails on any condition
# never evaluated and on any error check whose error arm was never seen,
# unless a line here keeps it; the format and the matching are in that
# script's header.
#
# ONE LINE PER ARM:
#
#     <file> <function> <TRADE-n> <systems> <condition>
#
# <function> is as the gate prints it, Type.Method for a method. <TRADE-n> is
# the entry in TECH_DEBT.md's trade-off register that keeps the arm, and
# scripts/check-tradeoffs.sh fails a line naming one the register does not
# hold. <systems> is "any", or the GOOS values on which the arm goes unseen,
# joined by commas. <condition> is the code gobco prints for it.
#
# Every other arm the gate names is a test to write, not a line to add. A line
# whose arm a test has come to reach fails the gate until it is removed, so
# this list only shrinks as tests arrive. Lines are not numbered here: they
# drift, and the gate matches on file, function and condition.
