# Per-directory file budgets. The gate is scripts/check-package-size.sh; the
# metric and its reasoning live in that script's header.
#
# ONE ENTRY PER LINE, of one of three kinds:
#
#     <repo-relative dir>   <budget>              a ratcheted budget
#     <repo-relative dir>   <ceiling> cohesive    a cohesive ceiling
#     <repo-relative dir>   exempt                not counted at all
#
# Every entry MUST carry a `#` comment on the line(s) DIRECTLY above it saying
# why the number is that number — not what the directory is. The script fails
# on an entry without one.
#
# A DIRECTORY NOT LISTED answers to DEFAULT_MAX_FILES, which lives in the
# script and is deliberately NOT restated here: a number spelled in two places
# is exactly the drift this gate exists to catch. Run
# `scripts/check-package-size.sh --list` to see it applied. That default is the
# standing decision — no grouping grows past it without a written reason — not
# an escape hatch. Registration is earned by size, which is what keeps this file
# short and every line in it load-bearing. Deleting an entry does not dodge the
# gate: an over-budget directory falls back to the default and fails harder.
#
# A RATCHETED BUDGET IS ZERO-HEADROOM IN BOTH DIRECTIONS. A file count only
# moves when someone deliberately creates a file, which is exactly the moment
# worth a thought — so a budget is the count on the day it was registered, and
# the next file trips the gate. A budget left ABOVE its count fails too; that is
# what a forgotten post-split ratchet looks like.
#
# A COHESIVE CEILING is for a grouping that is file-per-concern BY DESIGN: one
# responsibility spelled one file per pane, per endpoint or per command, which
# grows by a file each time the surface gains one and which CLAUDE.md says must
# not be split to chase a number. Zero headroom there was a ritual — every bump
# gave the same WHY and none ever led to a split — so such a grouping answers
# to a ceiling instead: it fails only past it, has no ratchet, and its comment
# names the spelling rule that makes it cohesive rather than listing its files.
# Raising a ceiling is a decision like any bump: rewrite the WHY and append a
# row to scripts/package-size-budget-history.md.
#
# Counts here are SOURCE files: unit tests (`*_test.go`, `*.test.ts(x)`),
# stylesheets (`*.css`) and generated code (`*.gen.go`, a whole generated tree
# marked `exempt`) do not count. But integration tests (`*_integration_test.go`)
# and everything under `web/e2e/` (Playwright specs and helpers) DO count — an
# end-to-end surface piles up one scenario at a time, and the budget is what
# forces it into per-surface folders instead of a hundred files in one. The
# budget measures concerns, not artifacts.

# internal/config — the .workflow.json loader, one file per config section: the
# root Config with its load and save (config.go, load.go, save.go), credential
# redaction and secret resolution (redact.go, secret.go), the messaging mode
# rules (modes.go), and a file per configurable section, each carrying its own
# validation — branch, commit, pull_request, store, taskwarrior, timing, ui,
# version and views. One responsibility (read, validate and save the
# configuration) spelled section-per-file; it grows only when a feature adds a
# section, which is a deliberate decision. 13 registered pull_request.go
# (FEAT-14) and store.go (FEAT-67) as they crossed the default budget; 14 is
# ui.go, the terminal's section moved out of config.go to carry the validation
# it had gone without; 15 is taskwarrior.go, the optional Taskwarrior
# integration's program and switch; 16 is layers.go, which finds the home and
# repository files and reads and saves the repository's as a layer over home.
internal/config 16

# internal/forge — GitHub and GitLab: the client and its transport (client.go,
# host.go, token.go, reason.go), the remote a repository names (remote.go),
# pull requests and their templates (pulls.go, templates.go), issues
# (issues.go), each forge's dialect (github.go, gitlab.go), CI (ci.go,
# githubci.go, cijobs.go — a failed pipeline's failed jobs, with their stage and
# why), and GitLab's people (members.go — users looked up by name, and a
# group's active direct members). One responsibility (speak to the forge)
# spelled concern-per-file; 13 is cijobs.go, kept out of gitlab.go (near the
# 500-line target) when CI began to say why a pipeline failed; 14 is
# members.go, which lets a CODEOWNERS group review as its people and took the
# user lookups out of gitlab.go with it, for the same reason; 15 is
# activity.go, what you did on the forge over a period for the Summary, read
# by searches on GitHub and from your events on GitLab, beside the issues and
# pull requests it reads them out of rather than inside either file.
internal/forge 15

# internal/tui — the Bubble Tea interface, spelled one file per pane, overlay
# and composer. Every file hangs its behavior off the one shared Model, so the
# package cannot be split without threading that Model, and the methods on it,
# across a package boundary Go does not allow; CLAUDE.md names it as the
# package that must not be split to chase a number. A new pane or overlay is a
# new file, so it answers to a ceiling: 80 is the 64 files it held when the
# kind came in and the panes and overlays still to come, and reaching it is
# where the package's shape is looked at again. layout/ and frame/ are already
# the pure leaves that could leave.
internal/tui 80 cohesive

# internal/webserver — the loopback REST surface, spelled one file per
# operation (or per pair of writes that share their checks) beside the shared
# guard, errors, wire shapes, stream and server. One responsibility (turn a
# guarded request into a seam call and a DTO) that grows only when the API
# gains an operation, a decision api/openapi.yaml records first, so it answers
# to a ceiling: 40 is the 31 files it held when the kind came in and the
# operations still to come, and reaching it is where the surface's shape is
# looked at again.
internal/webserver 40 cohesive

# internal/cli — the Cobra command tree, spelled one file per command (or per
# section of a command that outgrew one, as doctor's did). One responsibility
# (turn a command line into a wiring seam call and printed output) that grows
# when the tool gains a command, which the docs reference records, so it
# answers to a ceiling: 28 is the 20 files it held when the kind came in and
# the commands still to come, and reaching it is where the tree's shape is
# looked at again.
internal/cli 28 cohesive

# internal/loop — the loop composed once for the command line, the terminal

# internal/wiring — connects every surface's seams to the real clients: one

# web/src/lib — the web's shared drawing primitives, each drawn in one place
